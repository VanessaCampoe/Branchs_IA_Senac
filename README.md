## 📚 Fundamentos da biblioteca NumPy 

Este curso visa fornecer uma introdução sólida à biblioteca **NumPy** (Numerical Python), a ferramenta fundamental para computação numérica e científica em Python. Aprenderemos a manipular arrays de forma eficiente, realizar operações vetoriais e explorar os recursos essenciais desta biblioteca poderosa.

---

### Módulos do Curso

O curso está estruturado nos seguintes tópicos iniciais:

#### 1. Conhecer a biblioteca e nossos dados

* **Introdução ao NumPy:** Entenda o que é a biblioteca NumPy, por que ela é crucial no ecossistema de Data Science e suas principais vantagens sobre as listas nativas do Python.
* **O Objeto `ndarray`:** Conheça a estrutura de dados central do NumPy, o **array N-dimensional** (`ndarray`). 
* **Preparação de Dados:** Aprenda a carregar e a criar seus primeiros arrays, preparando os dados para a análise e manipulação.

---

#### 2. Exploração dos dados

* **Atributos de Arrays:** Descubra como inspecionar arrays usando atributos como `shape` (dimensões), `ndim` (número de dimensões), e `dtype` (tipo de dados).
* **Indexação e Fatiamento (Slicing):** Domine as técnicas de acesso a elementos, linhas, colunas e sub-arrays, essenciais para isolar partes específicas dos dados.
* **Reforma e Redimensionamento:** Aprenda a mudar a estrutura de um array, por exemplo, de um vetor para uma matriz (usando `reshape`), sem alterar seus dados.

---

#### 3. Operação entre arrays

* **Operações Aritméticas Elemento a Elemento:** Entenda como o NumPy facilita a realização de adições, subtrações, multiplicações e divisões de forma rápida e eficiente em todos os elementos de arrays.
* **Broadcasting:** Descubra o mecanismo de **Broadcasting** do NumPy, que permite operações entre arrays de diferentes formas e dimensões, sob certas regras.
* **Funções Universais (ufuncs):** Explore funções pré-compiladas, como `sqrt`, `sin`, e `exp`, que operam em arrays em alta velocidade.

---

#### 4. Números aleatórios

* **O Módulo `numpy.random`:** Aprenda a usar o submódulo `random` para gerar dados aleatórios, fundamental para simulações e criação de conjuntos de dados de teste.
* **Distribuições Comuns:** Geração de números aleatórios a partir de distribuições de probabilidade comuns, como a distribuição **uniforme** e a **normal (Gaussiana)**.
* **Definindo a Semente (`seed`):** Entenda a importância de definir uma semente para garantir a **reprodutibilidade** de seus experimentos.
